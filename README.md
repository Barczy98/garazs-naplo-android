# Garázs napló – Android

Az androidos változat. A kód ugyanaz, mint az iPhone-os `Barczy98/garazs-naplo` repóban, csak a `config.js` különbözik:
- platform: `android` (Google Naptár gomb + naptárfájl Samsung Naptárhoz, ujjlenyomatos feloldás szövegei),
- külön tárhelynevek, hogy ugyanazon a telefonon se keveredjen az iPhone-os változattal.

Telepítés: Chrome-ban megnyitni a https://barczy98.github.io/garazs-naplo-android/ oldalt, majd ⋮ menü → Telepítés alkalmazásként.
